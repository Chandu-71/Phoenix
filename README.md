# Phoenix 🐦‍🔥

> A self-healing LLM gateway for reliable AI applications.

Phoenix is an LLM gateway designed to improve the reliability of AI applications by detecting failures and automatically recovering from them.

The project is currently under development.

## Goals

- Route requests to LLM providers
- Detect failures and degraded responses
- Automatically recover from failures
- Provide fallback mechanisms
- Monitor gateway health and performance
